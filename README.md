# linux-rust

An experimental, AI-assisted proof-of-concept reimplementation of the Linux kernel as a modern Rust-based 64-bit OS and microkernel. This repository demonstrates a large-scale AI-generated system design and implementation; it is not production-ready.

---

## Project snapshot

- Title: Linux Kernel — Complete C-to-Rust Rewrite (Gemini 3.8)
- Nature: Experimental / educational proof-of-concept
- Languages: Primarily Rust (with small amounts of Shell, Python, Assembly, Makefile, and Perl)
- Repository: https://github.com/sagnikrout/linux-rust

---

## Important — AI assistance, attribution, and transparency

This codebase was produced with significant assistance from Google Gemini 3.8. Human contributors provided architecture guidance, prompting strategy, validation testing, and curation.

Because the codebase contains AI-generated content, we are explicit and transparent about what that means:

- Large portions of the architecture, scaffolding, and many source files were generated by an AI model. Human reviewers validated, tested, and edited portions where noted, but much of the code remains generated.
- The project is a research/educational artifact. Treat it as experimental software and not as a secure or stable kernel.
- If you redistribute, reuse, or adapt material from this repository, clearly disclose the AI-assisted origin and record what parts were manually modified.
